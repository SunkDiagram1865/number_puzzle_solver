# 数字华容道求解器 v3.0

**识别增强 + 还原图拖动微调** · 发布于 2026-10-26

---

## 概览

v3.0 不改变求解内核，集中解决 v2.0 图片识别最影响体验的两个问题：

- **参考图匹配不准**：定位并修复了「格距搜索范围」「偏移相位歧义」「参考图类型」三处根因。在离线合成测试集上，随机 40 例的完全正确率从 **14/40** 提升到 **40/40**，格子准确率从 **52.8%** 提升到 **100%**。
- **识别结果难以修正**：识别还原图现在可以直接拖动换块，下方数字实时同步。识别错一两块时，不必再把整盘数字重新敲一遍。

本次没有引入任何新依赖，主程序仍是**单文件、零依赖、可离线双击运行**；也没有上 OpenCV.js / ONNX / PyTorch —— 实测表明瓶颈在几何定位与对齐，而不是缺少神经网络。

## 新增：还原图拖动微调

### 支持的拖放

| 操作 | 行为 |
| :--- | :--- |
| 拖动一块到另一块上 | 交换这两块，下方数字同步交换 |
| 拖动过程 | 半透明「幽灵块」跟随指针；蓝框标出源块，橙框标出落点 |
| 右下角空格 | 固定为空格，不作为拖动目标 |
| 手工修改数字 | 还原图同步重绘，预览与输入框始终一致 |
| 状态栏 | 提示交换了哪两个数字，并实时判断局面是否可解 |

> **关于奇偶性**：单次交换两块会翻转排列奇偶性，使局面变为不可解。这是滑块谜题的数学性质，不是缺陷。状态栏会明确提示「单次交换会改变奇偶性」，再交换一次即可恢复。

### 实现

- `drawReconPreview` 扩展为支持「当前盘面 + 高亮槽」；
- 新增 `reconSlotAt`（坐标吸附格子）、`reconMakeGhost`（从截图裁出跟随指针的块）、`reconSwapTiles`（交换并回写数字）、`onReconDown / Move / Up / Cancel`；
- 使用 Pointer Events，同时覆盖鼠标与触屏（`touch-action: none`）；
- 识别结果、拖动状态、输入框通过 `RECON` 单一状态源保持同步；`refreshReconFromInputs` 让手工改数字时预览跟着重绘。

## 识别增强：参考图匹配 v2

### 问题定位

用离线合成的「图片华容道」截图（随机图片 → 切块 → 打乱 → 带 UI / 间隙 / 留白渲染）量化旧实现，定位到三处根因：

| 根因 | 实测现象 |
| :--- | :--- |
| **格距搜索范围只有 `±22%`** | 截图带 UI 顶栏时，真实 pitch=118 落在范围外（下限 119.7），拟合出 127.7，整盘错位 |
| **偏移存在整格距相位歧义** | 边界打分对「整体平移一整格」不敏感，无法判断哪一行才是第 0 行，网格可能整行错位 |
| **参考图被当成「干净原图」** | 如果参考图其实是**已还原的游戏截图**（带 UI / 间隙），整图拉伸或居中裁切都会错位 |

旧描述子是 24×24 灰度 NCC，且不处理方块间隙，对带间隙 / 边框的图片也偏弱。

### 新算法

```
参考图匹配 v2
 ├─ 边缘能量 → 平滑 → 取连续高能区，端点精修到强边缘，得到棋盘范围
 ├─ 正方形先验：两轴共用格距、联合打分；偏移用棋盘外沿锚定，消除相位歧义
 ├─ 按「棋盘外沿 + 格距」切格，并搜索 0 / 8% / 16% 三档间隙
 ├─ 参考图三种对齐（择优）：
 │    整图拉伸 / 居中裁切 / 按「已还原板面」拟合参考图自身网格
 ├─ 每块计算 24×24 彩色三通道 NCC，匈牙利算法求全局最优一一匹配
 └─ 返回盘面、空格位置、对齐方式与平均相似度
```

关键函数：`rgvSpan`（棋盘范围）、`rgvFitSquare`（双轴联合拟合 + 外沿锚定）、`rgvRefineOffsetNear`（锚点附近精修偏移）、`rgvExtractTiles`（间隙感知切格）、`rgvGoalThumbs`（三种参考图对齐）、`rgvNccColor`（彩色 NCC）、`rgvMatchRef`（匹配主流程）。

无参考图的边缘拼接路径也改用新的方形锚定网格拟合，避免同类错位。

## 变更

### 交互

- **还原图可拖动换块**：拖动一块到另一块上即交换，下方数字同步更新；
- 状态栏在参考图模式下显示实际采用的对齐方式（整图 / 居中裁切 / 已还原板面），便于判断参考图类型是否用对；
- 手工修改数字时，还原图同步重绘。

### 代码

- 新增 `rgv*` 系列纯函数，保持「只依赖像素数组」的可测试性；
- `recognizeFromPixels` 在检测到参考图时直接分派给 `rgvMatchRef`，无参考图时走边缘拼接；
- 按间隙预先抽取截图块，避免在三种参考图对齐中重复计算；
- 删除已不可达的旧参考图分支（整图拉伸 / 居中方形两种固定裁切）。

### 修复

- **格距搜索范围过窄**：不再用 `总尺寸 / N ± 22%`，改为先估计棋盘范围、再用正方形先验联合拟合；
- **偏移整格距相位歧义**：改用棋盘外沿锚定偏移，偏移只在外沿附近精修；
- **参考图是已还原截图时必然错位**：新增「对参考图自身做板面拟合」的对齐候选；
- **方块间隙污染描述子**：新增 0 / 8% / 16% 间隙搜索，切格时避开间隙与边框。

## 已知限制

1. **识别增强的验证基于合成数据** —— 真实截图若带圆角 / 阴影 / 叠加数字，或游戏对图片做了 letterbox（上下留黑边），仍可能出错；提供样图可继续调优。
2. **无参考图的边缘拼接仍是 60% ~ 80%** —— 本次只增强了网格拟合，未改变拼接思路；有参考图时优先用参考图模式。
3. **单次拖动交换会改变奇偶性** —— 交换两块后局面可能变为不可解，再交换一次即可；状态栏会提示。
4. **6 阶以上没有最优解** —— 受状态空间规模限制，属数学约束而非实现缺陷。
5. **图片识别假设目标局面右下角为空格** —— 与程序内置的目标盘面 `1,2,…,N²-1,0` 一致。
6. **不保存历史记录** —— 刷新页面即清空。
