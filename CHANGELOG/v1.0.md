# 数字华容道求解器 v1.0

**首个正式版本** · 发布于 2026-10-24

---

## 概览

一个零依赖、单文件的网页版数字华容道（N 数码 / Sliding Puzzle）求解器，支持 **3×3 ~ 8×8**。

设计原则只有一条：**要么给最优解，要么如实说明给不了。**

- **3 ~ 5 阶**：IDA\* + 曼哈顿距离 + 线性冲突，返回理论最少步数，已用 BFS 与独立 A\* 交叉验证；
- **6 ~ 8 阶**：最优解在数学上不可行（8×8 状态数约 10⁸⁹），改用逐层构造法，毫秒级返回合法可行解，绝不伪装成"最优"。

无后端、无构建、无第三方库，双击 HTML 即可使用。

- **结果可信**：最优解模式下返回的步数经过 BFS 全图精确距离与独立 A\* 双重验证，不是估算值

## 新增功能

### 求解核心

- **最优解求解器（`solvePuzzle`）**
  IDA\* 迭代加深搜索，启发函数为「曼哈顿距离 + 2 × 线性冲突」；置换表按迭代轮次清空（避免旧阈值下的误剪枝），记录每个局面的最小 `g` 值，容量上限 120 万条；同时限制搜索节点数与耗时。
- **快速解求解器（`solveConstructive`）**
  逐层剥离：循环归位当前子棋盘的最上一行与最左一列，子棋盘缩小一圈，末尾 3×3 用 BFS 精确求解（181 440 个可达状态）。
- **单块搬运（`bringTile`）**
  以 `(空格位置, 目标块位置)` 为状态的二元组 BFS，其余块视为无差别杂物，天然规避"空格被推进死胡同"的死锁，状态数上限 4 096。
- **成对归位（`placeTwo`）**
  行/列最后两格构成"角落 + 死角"，单独推动必然失败；改用 `(A位置, B位置, 空格位置)` 三元组 BFS（状态数上限约 26 万），自动推导"先摆形再旋转"的策略。

### 交互与校验

- **可解性检测**：基于逆序数与空格行号奇偶性，非法局面直接拒绝并说明原因
- **逐步演示**：播放／暂停／单步前进／单步回退，当前步骤在序列中高亮并自动滚动
- **播放速度**：20 / 70 / 160 / 400 ms 四档
- **随机打乱**：从有序状态随机游走，保证生成可解局面
- **粘贴导入**：粘贴一串数字自动铺满棋盘
- **键盘导航**：方向键在输入格间移动
- **自适应布局**：深色主题，字号随阶数与视口缩放

## 已知限制

1. **6 阶以上没有最优解** —— 受状态空间规模限制，属数学约束而非实现缺陷。
2. **个别极端 4×4 局面会超时** —— 例如理论最优 80 步的局面，程序会明确提示"未能确定最优解"，不会返回错误答案。
3. **5×5 难题可能耗时数十秒** —— 界面提供进度显示与「取消计算」。
4. **构造解不是最短解** —— 8×8 平均约 802 步，理论最优约 120 ~ 200 步。
5. **不保存历史记录** —— 刷新页面即清空。
6. **暂不支持图片拼图** —— 当前为数字版；图片模式需要额外的图像识别/映射层，已列入路线图。
